## Key decisions made

1. **influence2 = manager, characters = performers.** Never the reverse. Boundary is propose_post draft + analytics snapshot.
2. **Jev via OpenRouter, not TypeSafe key.** `typesafe/jev-router` model works, no separate key needed.
3. **Standalone channels, shared manager.** Each YouTube channel = own entity, all flow through same workflows.
4. **Revenue is terminal signal.** Views = attention, purchases = love. Manager reads both.
5. **We create characters (no external creators).** Closed loop: factory → channels → merch → revenue → better characters.
6. **Human gates at every consequence.** Workflows literally cannot complete past escalate without human state. Nothing ships/spends/sends without approval.
7. **Honest degradation everywhere.** No data → hold (not hallucinated winners). Blocked captions → failed transcript (not fake). Empty sift → fallback (not crash).
8. **Rate-based scoring, not volume.** Phoenix ranks engagement rate over raw views. Quality over volume.
